# Big Data and Operational Efficiency: Project Plan

A project plan and research design for a study of how big data technologies affect
operational efficiency in a selected higher education organisation.

## Status

This repository contains a project plan and research design. It does not currently include interview responses, completed analysis or measured operational improvements.

## Aim
To assess how big data technologies support operational efficiency, and what challenges
and benefits arise when they are used for decisions about students and administration.

## Project plan
The Gantt chart (`project_gantt_chart.xlsx`) breaks the project into phases:
- **Initiation:** establish goals, stakeholder engagement, feasibility analysis, approval process
- **Planning:** detailed project plan, risk identification and mitigation, budget finalisation, communication strategy

Each task has start and end dates, a duration and dependencies.

## Research approach
Stakeholder interviews, using the question guide in [the interview question image](research/Interview%20quetions.jpeg).
The questions cover:
- how big data supports operational efficiency
- examples of data-driven decisions and their outcomes
- tools used to collect and analyse data
- data security, privacy and ethical use
- staff training and stakeholder awareness
- improvements needed and future plans
